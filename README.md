A simple Python-based Study Plan Management Agent.

## Features

- Takes the student's name
- Takes the number of study days
- Takes daily study hours
- Allows subject selection
- Creates a topic-wise study schedule
- Adds daily revision timings
- Reserves the final day for previous-year question papers
- Gives separate timings for each previous-year question paper
- Includes full revision of all studied topics

## Subjects Included

- Python
- DBMS
- Operating Systems
- Computer Networks

## How to Run

Open the VS Code terminal and run:

```bash
python3 study_plan_agent.py
